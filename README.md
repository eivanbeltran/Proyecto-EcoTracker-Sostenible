# Proyecto-EcoTracker-Sostenible
proyecto final unidad2
Requisitos:

Java Development Kit (JDK) 8 o superior.

IDE NetBeans 8.2 (opcional para desarrollo) o terminal del sistema operativo.

Instalación y Configuración:

Clona el repositorio o descarga el código fuente en un proyecto de NetBeans 8.2.

Abre el proyecto y compílalo usando el botón Clean and Build.

Ejecuta la clase EcoTracker.java.

Uso:
Al iniciar, el programa desplegará un menú interactivo en la consola. Escribe el número correspondiente a la acción que deseas realizar y presiona la tecla Enter. Sigue las instrucciones en pantalla para ingresar tus datos (ej. kWh consumidos) y obtén tus resultados instantáneamente. Selecciona la opción 4 para cerrar el programa liberando la memoria (RAM) correctamente.
